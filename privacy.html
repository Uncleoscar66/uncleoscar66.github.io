Privacy policy for Jarvis

Last updated: 17 November 2026

Jarvis is a personal assistant used by a single person, its owner, on the owner's own computer. It is not offered to the public. This policy explains how Jarvis handles data, including data from Google APIs such as the YouTube Data API.

What Jarvis accesses

With the owner's permission, given through Google's sign-in and consent screen, Jarvis can access the owner's YouTube account to:

  • search YouTube videos;
  • open and play a video in the owner's web browser;
  • list the owner's YouTube playlists;
  • add a video to a playlist the owner names.

Jarvis only does these things when the owner asks. It never deletes videos or playlists.

Where data is stored

Sign-in tokens and settings are stored only on the owner's own computer. Jarvis has no server and no database, and it does not copy YouTube data anywhere else. Results are used to answer the owner's request and are not kept afterwards.

Sharing

Jarvis does not sell, rent, share or transfer any data to anyone. It uses no advertising, analytics, tracking or cookies. This website itself collects nothing.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting Jarvis's local settings on the computer removes all stored tokens.

Changes

If this policy changes, this page will be updated and the date above changed.
